# SLIME FORUM
🟢 SLIME FORUM

SLIME FORUM est un forum anonyme en ligne qui fonctionne directement dans le CMD / terminal. Il n’y a pas besoin d’ouvrir un site web pour discuter : une fois le programme lancé, toute l’interface du forum apparaît directement dans ton terminal.

Le forum fonctionne sur Windows, Linux et macOS. Toutes les versions sont connectées au même serveur, ce qui permet à un utilisateur Windows de voir les publications envoyées depuis Linux ou macOS, et inversement.

📥 Installation et lancement

Commence par télécharger SLIME FORUM puis décompresse complètement le fichier ZIP. Il ne faut pas lancer les fichiers directement depuis l’archive ZIP.

🪟 Windows

Ouvre le dossier :

WINDOWS

Puis double-clique simplement sur :

SLIME_FORUM_WINDOWS.bat

Une fenêtre CMD va s’ouvrir et SLIME FORUM va démarrer.

Lors du premier lancement, le programme peut prendre un peu plus de temps car il prépare automatiquement son environnement Python et les dépendances nécessaires.

Ensuite, les prochains lancements seront plus rapides.

🐧 Linux

Ouvre le dossier :

LINUX

Puis lance :

SLIME_FORUM_LINUX.sh

Le programme démarre dans le terminal Linux et l’interface s’adapte automatiquement à la taille de celui-ci.

Selon la distribution Linux et le gestionnaire de fichiers utilisé, il peut être nécessaire de choisir « Exécuter » ou « Lancer dans un terminal » lorsque Linux demande quoi faire avec le fichier .sh.

🍎 macOS

Ouvre le dossier :

MACOS

Puis lance :

SLIME_FORUM_MAC.command

Le Terminal de macOS s’ouvre avec SLIME FORUM.

macOS peut afficher un avertissement de sécurité lors du premier lancement d’un script téléchargé depuis Internet. Dans ce cas, il faut autoriser son ouverture dans les paramètres de sécurité de macOS.

Le menu principal propose trois choix :

01 > Voir les infos d'autres utilisateurs
02 > Publier une information
03 > Quitter

Tu tapes simplement :

01

pour consulter les publications.

Choisis :

02

pour créer une nouvelle publication.

SLIME FORUM te demande alors ton pseudo, puis ton message.

Pendant la rédaction :

Entrée

permet de revenir à la ligne sans publier immédiatement.

Lorsque ton message est terminé :

Ctrl + Entrée

permet de l’envoyer sur le forum.

La publication est alors envoyée au serveur commun et devient accessible aux autres utilisateurs de SLIME FORUM.

Enfin :

03

permet de quitter proprement le programme.

🌐 Un forum commun

Il n’est pas nécessaire de configurer manuellement une adresse de serveur. Le client est déjà configuré pour rejoindre le serveur SLIME FORUM.

Cela signifie que tous les utilisateurs rejoignent le même espace de publications, quel que soit leur système :

Windows ─┐
         │
Linux ───┼──► SLIME FORUM ◄──► Publications
         │
macOS ───┘
👤 Anonymat

SLIME FORUM fonctionne sous pseudonyme.

Il n’y a pas de création de compte traditionnelle et le forum ne demande pas de nom réel ni d’adresse e-mail pour publier. Tu choisis simplement ton pseudo lorsque tu souhaites envoyer une publication.

⚙️ Technologie

SLIME FORUM est développé en Python avec une interface spécialement conçue pour fonctionner directement dans les terminaux Windows, Linux et macOS.

L’objectif est simple :

Télécharger → décompresser → lancer → choisir un pseudo → publier.

Pas besoin d’utiliser une interface web : le forum reste directement dans ton terminal.
